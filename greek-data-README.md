# Today's Greek Dictionary

Greek lexicon / dictionary created by Ray Geide as part of the Breakthrough Versions / Today's Bible project.

This folder contains a full export of the lexicon in JSON format.

## File

- **greek-data-nopt.json** – Complete lexicon data

The entries are ordered by Strong’s number.

## Fields in each entry

| Field              | Description |
|--------------------|-----------|
| `id`               | Internal database ID |
| `strong_number`    | Strong’s number (e.g. G1, G2, …) |
| `greek_word`       | Greek word (with accents and breathing marks) |
| `transliteration`  | English transliteration |
| `pronunciation`    | Pronunciation guide |
| `part_of_speech`   | Grammatical category |
| `etymology`        | Origin / etymology notes |
| `definition`       | Translation used in the Today's Bible (a part of the Breakthrough Versions project) |
| `kjv_terms`        | How the word is translated in the KJV |
| `references_list`  | New Testament occurrences |
| `comments`         | Additional notes by the translator |
| `dodson`           | Definition from Dodson |
| `mounce`           | Definition from Mounce |
| `strongs`          | Definition from Strong’s |
| `thayer`           | Definition from Thayer |
